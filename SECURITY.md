# Security Policy

LAVA Training is an internal agent-training simulator operated by LAVA Automation. It issues no real
insurance and must only contain fictitious customer data.

## Reporting a vulnerability

Email **security@lavaautomation.com** with a description, steps to reproduce and the affected URL.
Do not open a public GitHub issue for security problems.

- We acknowledge reports within 2 business days.
- We aim to fix confirmed high or critical issues within 14 days, and others within 60 days.
- Please give us reasonable time to fix an issue before disclosing it.

## Supported versions

Only the current `main` branch (the production deployment) is supported.

## Data handling rules for users

- Enter fictitious data only. Never enter real names, Social Security numbers, driver license
  numbers, bank or card numbers.
- On a shared computer, use **profile menu › Sign out and clear this computer**.
- Report a lost or shared password to an administrator so the account can be removed from `SITE_USERS`.

See [docs/SOC2-CONTROLS.md](docs/SOC2-CONTROLS.md) for the control inventory.
